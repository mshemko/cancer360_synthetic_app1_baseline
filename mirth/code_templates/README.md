# Mirth Code Templates

These JavaScript files are intended for Mirth Connect global code templates.

Suggested template library structure:

1. `uuid_helpers.js`
2. `date_helpers.js`
3. `csv_helpers.js`
4. `db_helpers.js`
5. `source_helpers.js`

Load them as global code templates, then call the helper functions from channel source/destination transformers.
